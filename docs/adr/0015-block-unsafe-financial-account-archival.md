# Block archival while a financial account still has effects

Personal Asset OS只允許封存已無目前資產、待履行義務或有效連結的金融帳戶。證券帳戶必須所有持股數量皆為零且沒有買入或賣出待交割款；銀行帳戶必須現金餘額為零、沒有待交割款，且未被任何有效證券帳戶設為預設交割銀行。這避免封存使資產、現金或交割義務從日常畫面消失；Owner須先完成交易、移轉現金或更換連結，而不能用封存繞過帳務。

## 拒絕與歷史

不符合條件時須整筆拒絕封存，列出非零持股、非零現金、待交割款或仍引用該銀行的有效證券帳戶。成功封存只停止未來使用，不得改變既有交易、持股歷史、現金事件、交割紀錄、損益或audit；封存及明確還原均須記錄帳戶、Owner確認時間及理由。
