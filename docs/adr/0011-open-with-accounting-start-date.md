# Open the ledger from a declared accounting start date

Personal Asset OS使用一個由Owner確認的帳務起始日快速開帳：每個銀行帳戶輸入當時已交割現金，每個證券帳戶及Asset輸入當時持有數量與移動平均成本，起始日前不要求補登完整交易。期初資料是正式開帳事實，不得偽造成買入、存款或其他歷史交易；因此系統不宣稱能計算起始日前的交易歷史或已實現損益，但自開帳時點起須完整記錄所有交易。

## 期初待交割款

帳務起始日前已成交但尚未完成T+2交割的買賣，允許以期初待交割款承接。Owner須輸入買入應付款或賣出應收款方向、最終金額、交割日、證券帳戶及交割銀行帳戶；期初持股及移動平均成本已包含這些交易在成交日產生的效果，因此期初待交割款在交割時只改變銀行現金，不得再次改變持股、成本或損益。期初買入應付款計入交割可用現金的扣減，期初賣出應收款在實際交割前仍不得抵扣買入義務。

## 稽核與更正

每筆期初資料須保存帳務起始日、帳戶、Asset（期初持股適用）、數量、移動平均成本、現金金額或待交割方向與金額、交割日、Owner確認時間及來源備註。已確認的期初資料不得直接修改或刪除；更正須保留原值與更正理由，並依交易更正規則重新驗證及計算其後全部帳務。

## 第一個可用版本的輸入範圍

第一個可用版本以清楚快速的手動表單輸入期初資料、買賣、現金事件、股利及更正，不包含任何券商專用CSV或Excel匯入，也不登入券商或銀行。未來增加檔案匯入時，匯入資料仍須經過與手動輸入完全相同的重複偵測、資金與持股驗證、Owner確認及audit，不得成為繞過帳務規則的批次寫入管道。
