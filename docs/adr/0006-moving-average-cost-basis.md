# Use moving average cost for stock transactions

Personal Asset OS以移動平均成本計算同一證券帳戶中同一Asset的持股成本與賣出已實現損益，不採FIFO或指定批次法。這與單一彙總Holding模型一致，能以較少操作提供穩定且可重算的私人資產損益；代價是Owner不能指定本次賣出對應哪一批買入股票，未來若改用其他成本法也必須重算全部歷史交易。

## 賣出限制與稽核證據

賣出數量必須小於或等於同一證券帳戶及Asset在該成交時點的可賣數量；超過時整筆拒絕，且不得改變持股、成本、待交割款或現金。每次接受或拒絕都必須記錄交易識別、證券帳戶、Asset、成交日、申請賣出數量、判定當下的可賣數量、判定結果，以及後續修正或重試的關聯；第一階段不允許放空或產生負持股。

同一成交日較早發生的買入可先增加可賣數量及更新移動平均成本，後續賣出可使用該數量並按更新後的成本計算已實現損益。每筆交易記錄成交日期及成交時間；同一秒成交或券商未提供時間時，由Owner明確指定先後序號。計算不得使用資料建立時間或輸入順序代替成交順序，且任何順序點都不得出現負持股。

## 股數與金額精度

台股買入、賣出及期初持股的股數只允許整數；買賣輸入須為正整數，持股計算結果須為零或正整數。系統不要求以一千股為倍數，因此整張與零股共用同一交易模型，但第一階段不支援小數股。成交價、移動平均成本、交易費稅、現金與損益仍使用精確Decimal計算，禁止使用浮點數。

## 合併成交

Owner可依券商對帳資料，將同一證券帳戶、Asset、方向及成交日中沒有反向交易穿插的一段連續成交合併輸入。合併成交以總股數、成交總額及Owner確認的最終費稅作為正式帳務資料，平均成交價由成交總額除以總股數衍生，不得以券商畫面上已四捨五入的平均價反推成交總額。若同日買入與賣出交錯並會改變可賣數量或移動平均成本，必須依實際先後拆成多筆交易；每筆合併成交須保存成交順序及選填券商對帳參考。

## 重複交易防護

每筆交易都有系統產生的內部識別；Owner可另外輸入券商提供的委託書號、成交序號、對帳交易編號或其他券商參考編號。在同一證券帳戶內，相同券商參考編號不得確認第二次，系統須硬性拒絕並指出既有交易。

券商未提供參考編號時，若證券帳戶、Asset、方向、成交日期與時間、股數、成交總額及最終費稅與既有交易高度相同，系統須列出疑似重複的既有交易；Owner只有再次確認並填寫建立原因後才能繼續。稽核須保存比對欄位、候選交易識別、警示結果、Owner決定、原因及確認時間。
