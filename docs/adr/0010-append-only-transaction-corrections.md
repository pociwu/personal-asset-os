# Preserve confirmed transactions through linked corrections

Personal Asset OS禁止直接修改或刪除已確認交易；Owner須建立參照原交易的更正紀錄，以新內容取代原交易的帳務效果，同時永久保留原始內容。這選擇可追溯的更正鏈而非就地覆寫，代價是每次更正都必須從最早受影響的成交順序重新計算後續持股、移動平均成本、已實現損益、待交割款及現金。

## 稽核證據

每次更正須保存原交易識別、更正交易識別、更正理由、更正前後的正式交易內容、Owner確認時間，以及重算的起點、範圍與結果。更正及其衍生重算必須形成單一可追溯結果，不得留下部分使用舊資料、部分使用新資料的帳務狀態。

## 更正衝突

確認更正前須先以候選內容完整重算所有受影響的後續交易，不得提前改動正式帳務。只要任一結果造成超賣、負持股、交割現金不足或其他領域規則違反，就整筆拒絕更正並一次列出全部衝突，包括受影響交易、衝突類型、成交順序及計算值；Owner須先依序更正相關交易後再重試。

## 補登交易

Owner可補登帳務起始日後遺漏的舊交易；交易須依實際成交日期、時間及序號插入原成交順序，不能依系統建立時間排在帳本最後。確認前須從插入點完整預演後續持股、移動平均成本、損益、待交割款與現金，任何超賣、負持股、交割現金不足或其他規則衝突都整筆拒絕並列出全部受影響交易。成功補登須同時保存實際成交時間、系統補登時間、Owner確認時間及完整重算範圍與結果。
