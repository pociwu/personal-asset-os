# Use official daily closing prices in the first usable release

第一個可日常使用版本每日自動取得TWSE及TPEx發布的正式收盤價，用於計算目前市值、未實現損益及總投資損益，不再以Mock價格呈現Owner的正式資產資料。第一階段只提供日收盤價，不提供盤中或即時行情；測試資料仍須與正式財務資料隔離。

## 來源與更正

每筆正式價格須保存市場、Asset、市場日期、價格、官方來源及取得時間。Owner可在官方資料錯誤或缺漏時建立更正，系統須保留原始價格、更正價格、理由及確認時間；已保存價格不得直接覆寫或刪除。

## 缺漏與降級

休市、當日價格尚未發布或官方來源暫時失敗時，可沿用最後一次成功取得的正式收盤價，但每個使用處都須顯示實際價格日期及過期警示，不得將它描述為當日價格。若某Asset從未取得任何正式或Owner確認價格，其目前市值、未實現損益及依賴該價格的總投資損益皆為未知，不得使用`0`代替。每次取得失敗須保存目標市場日期、官方來源、嘗試時間及失敗狀態，且不得記錄credential或secret。

## 部分定價

只要投資組合中任一有效持股沒有可用價格，整體目前市值、未實現損益及總投資損益都須標示為估值不完整。系統可顯示已取得價格之持股的「已定價市值小計」及「已定價未實現損益小計」，但不得稱為總計；同一畫面須列出所有未定價的證券帳戶、Asset及缺價狀態，讓Owner知道數字未涵蓋哪些持股。
