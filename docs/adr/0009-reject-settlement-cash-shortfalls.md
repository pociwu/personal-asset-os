# Reject buys that create a settlement cash shortfall

Personal Asset OS不得確認會使指定交割銀行帳戶在交割日現金不足的買入交易；持股、交易、待交割款及現金紀錄必須全部不變，Owner須先修正銀行起始餘額、既有現金事件、待交割資料或本筆交易內容後再提交。這選擇帳務一致性而非容許負現金並警示，代價是即使外部交易已實際成交，只要系統中的資金資料不完整，Owner也必須先補正資料才能記錄該交易。

## Sufficiency rule

買入確認時的交割可用現金為「指定銀行帳戶已交割現金餘額－該帳戶所有未付款買入待交割應付款」。新買入應付款包含成交價款及Owner確認的最終交易費稅；只有新應付款小於或等於交割可用現金時才能確認。任何尚未交割的賣出應收款，即使與買入使用同一銀行帳戶、同一證券帳戶或同一交割日，也不得抵扣或增加交割可用現金。

例如已交割現金為`100,000`、既有買入待付款為`30,000`，交割可用現金為`70,000`：新買入應付款`60,000`可確認，`80,000`必須拒絕。若另有賣出待收款`50,000`，上述交割可用現金仍為`70,000`，直到該賣出款實際交割後才增加現金餘額。

## Audit evidence

每次買入確認或拒絕都須記錄交易識別、證券帳戶、交割銀行帳戶、成交日、自動及最終交割日、成交價款、費稅預估、Owner確認費稅、買入應付款、判定時已交割現金、既有未付款買入義務、計算出的交割可用現金、判定結果及後續修正關聯。Audit不得保存登入credential或secret。
