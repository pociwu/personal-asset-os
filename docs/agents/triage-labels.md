# Triage Labels

| Canonical role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待維護者評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由 Agent執行 |
| `ready-for-human` | `ready-for-human` | 需要人類執行或決定 |
| `wontfix` | `wontfix` | 已決定不處理 |

技能提到 canonical role時，使用本表對應的 GitHub label。
